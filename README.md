# 🦜 Polly — Feedback & Issues

This is the public issue tracker for **Meet Polly** website, a browser (for now) EPUB reader and
language-learning app. Upload an EPUB, read with paginated rendering, tap words
for AI-powered translations, and track your vocabulary as it grows from
*unknown* → *learning* → *known*.

**This repository contains no source code.** It exists solely so you can report
bugs and request features.

➡️ **Try Polly:** <https://meetpolly.app>

---

## 🐛 Found a bug? 💡 Have an idea?

1. **[Search existing issues](../../issues)** first — someone may have already
   reported it. If so, add a 👍 or a comment instead of opening a duplicate.
2. If it's new, **[open an issue](../../issues/new/choose)** and pick the
   template that fits:
   - **Bug report** — something isn't working as expected
   - **Feature request** — an idea or improvement you'd like to see

## ✍️ Writing a good report

The more detail you give, the faster we can help:

- **What happened** vs. **what you expected** to happen
- **Steps to reproduce** the issue
- Your **browser and OS** (e.g. Chrome 124 on macOS, Safari on iPhone)
- **Screenshots or screen recordings** if relevant
- For EPUB issues: where the file came from (without sharing copyrighted files)

> 🔒 **Privacy note:** Polly runs entirely in your browser — your books,
> vocabulary, and progress are stored locally in IndexedDB and never uploaded.
> Please don't paste private data into issues.

## 🗳️ Voting & discussion

- 👍 react to issues you care about — it helps prioritization.
- Keep comments constructive and on-topic.

## 🤝 Code of Conduct

Be respectful and kind. Harassment, spam, or abusive behavior won't be
tolerated and may result in being blocked from the tracker.
